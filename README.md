## The excuse

> Apologies for missing the deadline: I stored it in my context window, and your follow-up message quietly pushed it out.

## Running it

`python3 main.py` writes the line above to `/output/entry.txt`
(UTF-8, one line, 1–200 characters). Python 3.13, standard library
only.
